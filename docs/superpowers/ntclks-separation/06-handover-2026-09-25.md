## 4. 换机注意（环境差异）

- 旧机上 `cache/`、`buildsystem/` 是指向主检出缓存的符号链接（不入库）；新机直接
  `make fetch` 重建下载缓存（约 200MB+）。`make doctor` 会列出缺什么（OVMF=`edk2-ovmf`、
  tesseract、qemu-system-x86_64、mke2fs/mkfs.fat/mtools/xorriso/grub-mkstandalone 等）。
- 旧机 `/home/leon/build/ntclks-sep/` 下的全部构建输出/日志/截图**不迁移**（机器本地）。
  本文档即证据汇总；需要实证时按 §5 清单重跑。
- QEMU 测试需 KVM（`/dev/kvm`）与 `/usr/share/edk2/x64/OVMF*.4m.fd`；QMP socket 用 `/tmp`。
- 安装器测试用 `--install-timeout 3600`（默认 1200s 会截断健康安装，本机约 25 分钟；00§4）。
