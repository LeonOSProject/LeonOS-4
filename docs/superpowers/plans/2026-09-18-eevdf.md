# EEVDF 调度替换

目标：以本地 Linux 6.12 `kernel/sched/fair.c` 的 EEVDF 规则为参考，
独立实现 LeonOS 的公平调度策略，替换严格优先级轮转选择。

架构：每 CPU 公平域，共用现有 scheduler_lock 保证任务所有权和状态发布；
使用现有稳定任务表遍历，不直接移植 Linux 红黑树及内核依赖。
虚拟运行时间按 nice 权重累计，只有非负 lag 的任务可被选择，按虚拟截止时间排序。
睡眠保存有界 lag，负 lag 延迟出队，唤醒放置补偿新权重带来的平均值变化。
任务不在系统调用边界获得免费新时间片；yield 放弃当前请求；fork 清空子调度实体。
默认请求为一个现有 100 Hz 时钟周期，避免假装具备亚毫秒抢占能力。

- [x] 确定性测试：同权公平、不同 nice 比例、截止时间选择、资格、睡眠欠账、yield。
- [x] 内核策略实现及接入：运行记账、阻塞唤醒、退出、fork、nice、亲和性、空闲窃取。
- [x] 主机回归及来宾测试：进程线程进度、亲和性、nice、退出回收。查明生产内核禁用 AP，
  保留已有安全限制，多 CPU 选择/迁移仅通过主机模拟测试覆盖，不宣称 AP 并发可用。
- [x] 实际构建和安装 ISO，记录完成情况和与 Linux 6.12 的实现差异。
  Uinxed 来宾构建通过（1056.981 秒）；该长测早于最终休眠改权重修正，
  最终内核另通过策略/调度入口测试、公平性、内存和 chroot 来宾回归。

文件职责：`eevdf.h` 定义纯整数调度实体及数学运算；`sched/eevdf.inc`
实现任务表与每 CPU 公平域的集成；`sched.c` 保持进程生命周期和架构切换接口；
`tools/tests/eevdf_test.c` 用模拟时间执行真实策略，来宾测试校验实际系统行为。

验证命令：`python3 tools/test_eevdf.py`、`python3 tools/test_linux_threads.py`、
`python3 tools/test_linux_memory.py`、`python3 build.py run kernel`、
`python3 tools/test_execution_lock_qemu.py`，以及 Uinxed 来宾完整构建。
